# Markdown 标题修复规则

只修复已有行的标题识别和 ATX 层级，正文内容必须保持不变。

1. 文档题名通常为一级标题；一级章节通常为二级标题，依次递进，最深不超过六级。
2. 优先使用明确的章节编号、上下文和全文层级关系，不要只依据单行长度。
3. 普通正文、列表项、网址、联系方式、按钮文字、页眉页脚、图题、表题和目录中的点线页码项默认不是正文标题。
4. 已有标题若实际是正文，删除其 ATX `#`；漏识别标题则添加 `#`；层级错误只调整 `#` 数量。
5. 不合并、拆分、改写、补充或重排任何行；标题文字在 Markdown 中缺失时记录为未决。
6. 不修改正文措辞、空白、标点、公式、表格、图片链接、HTML、代码块和阅读顺序。
7. 无法确定时不要猜测，将问题写入返回 JSON 的 `unresolved` 数组。
8. 全文通常只保留一个文档题名 H1；Abstract、Introduction、Methods、Results、Discussion、References、Acknowledgements 等顶层章节通常同级为 H2。
9. 编号深度是层级证据之一：`1`、`1.1`、`1.1.1` 通常依次对应 H2、H3、H4，但必须结合全文结构，不能仅凭编号机械修改。
10. 作者、单位、邮箱、DOI、期刊元数据、页码和重复页眉页脚不是正文标题；不要为消除层级跳跃而把这些内容提升为标题。
