# 两轮 OCR 后训练实验独立复核(2026-09-18)

> 性质:独立取证复核——不复述文档结论,全部数字从原始产物重算;全程只读,未重跑任何评测/GPU 任务。
> 对象:第一轮 `pmc-fullce-16k`(Overall 0.7092)与第二轮 `pmc-readoc-spage-16k`(0.6709)的结论文档链。
> 复算脚本:`evaluation/review_20260918/verify{1-4}.py`(本地留档=服务器 `posttrain docs/review_20260918/`)。
> 术语约定:原文档所称"四板斧"在本文写作**四条检测规则**(行重复率≥0.3 / 输出长度≥2×GT / 塌缩≤1/3 / zlib 压缩比<0.15);"退化文档"按具体失效模式称为**复读/过生成/塌缩**文档。

## 1. 结论总览

1. 两轮文档的数字与主结论**经独立重算全部成立**(§7):缺口集中在少数失效文档;剔除后第一轮在健康文档上反超 fc;`<PAGE>`/`<table>` 计数、训练曲线、数据统计、页数拆分、验证门全部逐位复现。
2. 与原文档表述的**7 处出入**(§8),其中 4 处实质:新失效文档并非全为短文档;TEDS 跌幅分解数字对不上;"表格信号稀释 100%→71.5%"是行占比误用;标题回退不是面上现象。
3. 按现象归纳,**两轮共四个主要现象**(§2-§5):
   - **现象一:复读**——两轮掉分的主要直接原因,四类形态,循环内容不在训练数据 → 解码期问题;
   - **现象二:多页表格输出坍塌**——mix 相对 pmc 的最大增量损失,单页持平;"数据稀释"解释不充分,与"训练步数更多"存在混淆;
   - **现象三:长文档结构性简化**——长度正常但标题/表格悄悄减少,现有四条检测规则全部漏检;
   - **现象四:评分口径缺口**——模型未输出的表格不计 0 而是从计分池消失,表格损伤被低估。
4. **最大未决问题**:现象二究竟是"数据配方"还是"训练步数更多"导致——32k 续跑(同数据分布、更多步)是现成的分离实验,建议最先做。
5. 下一步方案与验收门见 §10:过采样含表 PMC 行(保留 READoc)+ A2 数字归一查重 + spage v2 含表格页 + 32k 诊断臂。

## 2. 现象一:复读(两轮掉分的主要直接原因)

### 2.1 现象

少数文档上模型输出出现复读:同一行/同一块/同一数列无限重复。第一轮 9 篇、第二轮 9 篇(另有塌缩文档,见原文档清单)。单篇 per-doc overall 损失 −0.11 ~ −0.76。

### 2.2 数据证据

- 检出计数(重算):base 6 篇、fc 8 篇、pmc 11 篇(严格 9+塌缩 2)、mix 12 篇(严格 9+塌缩 3)。
- 集合轮换(严格口径 9 vs 9):pmc 修复 6 篇 / mix 新增 6 篇 / 两轮共有 3 篇,名单与支线文档 §6.2 完全一致。
- **反事实(决定性)**:剔除 8 篇严格复读文档(双方同剔),pooled TEDS 变为 pmc **0.5296** vs fc 0.4999 / base 0.5002,Overall 差距由 −3.0pp 反转为 ≈+0.5pp → **缺口≈全部来自复读文档**。
- **循环内容不在训练数据**:把每篇的最长重复单元拿去检索 pmc-fullce-16k / pmc-spage-16k / readoc-view-16k 三套 train.jsonl,全部 0 命中。
- **排除输入自重复**:GT 侧行重复率 3-1跨页重复表头 0.01、4-1统计图2 0.07、2-1横向合并 0.11——pred 的高重复是模型行为,不是文档本身重复。
- mix 新增 6 篇的 GT 规模:仅 3 篇为短文档(445c / 1,151c / 2,472c),另 3 篇为 25p/26,955c、15p/8,953c、1p/4,255c。

### 2.3 Case(输出原文片段)

**Case 1|域漂移套话 + 块级复读**:`珠海机场_工作证管理细则_6`(mix,1 页)。GT 是机房临时工作证制度(445 字符),pred 52,522 字符:

TEL: 0755-822-8228

# pred 最长重复单元(14,942 字符,与 GT 内容完全无关)

模型在低信息量页面上漂移到"上市公司公告"文体并循环;循环内容与输入文档、训练数据均无关。

**Case 3|数列递增复读**:`4-1统计图2`(mix,单元 4,507 字符)与 `中车株洲_方案技术_6`(pmc,单元 32,328 字符):

### 2.4 问题总结

1. 复读是**解码期行为**,不是数据污染:循环内容训练数据零命中、GT 无自重复、pmc 轮单页同样复读(中车株洲_6)——"spage 教会单页复读"因果证据弱。
2. 现有解码防护(no_repeat_ngram_size=35、window 128/1024)挡不住:循环单元 115 字符~32k 字符远超 ngram 窗口;数列/计数器类每次出现的 ngram 都是新的。
3. 原文档"新病全为 GT<2.5k 短文档爆发"不成立(3/6 为长文档),短文档先验双峰假说只覆盖一半。

### 2.5 解决方案

- **A2 解码期复读抑制**(优先级最高、成本最低):块级重复检测,**比对前对数字做归一化**(否则 Case 2/3 抓不住)+ 表格行结构签名(抓 Case 4)。先只对复读文档做旁路推理验证,不改历史分数、不动主协议。
- 数据侧无直接对症手段(循环内容不在训练数据),不要再为"短文档过冲"单独设计数据干预。

## 3. 现象二:多页文档表格输出坍塌(mix 的最大增量损失)

### 3.1 现象

mix 相对 pmc:多页文档的表格发射量与质量大幅下降;单页文档完全持平。同时 mix 在健康文档上的文本能力是四路最好——收益与损失在不同部位。

### 3.2 数据证据

| 证据 | 数值 |
|---|---|
| `<table>` 发射(全库) | base 214 / fc 182 / pmc 195(单页 65 + 多页 130)→ mix 118(单页 **65 持平** + 多页 **53**) |
| 官方 pooled TEDS | 单页 0.7327→0.7343(持平);多页 0.3748→**0.2386** |
| 逐表求和 | pmc 122.5 → mix 84.0(−38.5);mix 12 篇复读文档内 −24.1(63%),非复读文档 −14.4(37%) |
| 非复读文档的最大跌幅 | 1-3单元格内换行1:28 张计分表共 15.34 分 → 20 张共 **0.26 分**;4-2段落:42 张 mean 0.421 → 35 张 mean 0.181 |
| union 同文档集(剔 19 篇严格复读文档) | TEDS:base 0.5902 / fc 0.5889 / pmc **0.6137** / mix **0.4683**;text_edit:mix **0.1749 = 四路最好**(0.1780/0.1760/0.1847);order 四路 0.043-0.046 无差 |
| merge 路径含表行占比 | pmc ~62-66% → mix ~52-56%(READoc 1,706 行与 spage 2,000 行均 0 表) |
| Overall 当量 | 健康集 TEDS 若恢复到 pmc 水平 ≈ **+4.4pp**;复读 12 篇治理 ≈ +4.5pp——两条腿同量级 |
| `<PAGE>` 发射 | base 181 → fc 149(**仅 213 步**)→ pmc 137 → mix 49,单调衰减 |

### 3.3 问题总结

1. 单页发射持平 → 现象二与 spage/单页路径无关,是 **merge 路径**行为改变。
2. "表格信号稀释"解释不充分:含表行占比只降 ~10pp,发射却降 59%,量级不成比例。
3. **步数混淆未排除**:mix 比 pmc 多训 463 步;`<PAGE>` 的单调衰减同样兼容"训练步数"解释。现有产物无法区分"数据配方"与"训得更多"。
4. READoc/spage 带来了真实文本收益(健康集 text 四路第一)——**剔除 READoc 会连收益一起丢掉**。

### 3.4 解决方案

1. **保留 READoc**,用 **PMC 含表 merge 行过采样**把 merge 路径含表行占比拉回 ≥75%(替代原文档"剔 READoc"选项)。
2. **spage v2 把表格页纳入**:现构建跳过全部表格页 → 单页样本 0 表;补上后 `document parsing.` 路径也有表格信号。
3. **32k 续跑作为诊断臂最先执行**(ckpt-400 就绪,续训 ≈7.2h+评测 1.6h):同数据分布更多步,若多页表格也坍塌 → 步数主导、稀释降级;若不塌 → 稀释坐实。这是唯一现成的混淆分离实验。
4. 验收直接量:多页 `<table>` 发射 ≥110(pmc 130×0.85)。

## 4. 现象三:长文档结构性简化(四条检测规则的盲区)

### 4.1 现象

个别长文档输出**长度正常**,但标题块与表格的数量/质量大幅下降——四条检测规则(重复率/长度比/塌缩/压缩比)全部漏检,混在健康集里。

### 4.2 数据证据(Case)

**Case:`4-2段落中带「图x-x」`(38 页,未被任何检测规则标记)**

| 指标 | pmc | mix |
|---|---:|---:|
| det-title 块数 | 85 | **27** |
| 计分表数 × mean TEDS | 42 × 0.421 | 35 × **0.181** |
| text_acc | 0.279 | **0.134** |
| 输出长度比 | 正常 | 正常(未触规则) |

同型:`1-3单元格内换行1`(35 页)28 张计分表 15.34 分 → 20 张 0.26 分。
全局:det-title 块 502→345 的构成 = 复读 12 篇内 −90 + **本文档单篇 −58** + 其余全部文档 −9(即标题回退集中在个例,不是面上现象)。

### 4.3 问题总结

长度正常的"悄悄减配"既不触检测规则、也不表现为单篇总分崩塌(被 text/order 项部分掩盖),但持续拖低健康集 TEDS,是健康多页 TEDS −12~15pp 的主力之一。

### 4.4 解决方案

新增监控指标并纳入验收:per-doc **det-title 块数**与**计分表数**对照 GT 表数;验收门增加"计分表覆盖率"(§10)。

## 5. 现象四:评分口径缺口(未输出的表格不计 0)

### 5.1 现象

评分池由**可匹配的 pred 表格**构成:模型未输出的 GT 表格不是计 0,而是从分母消失;单篇分数缺 TEDS 项时按剩余权重重新归一。两个口径都不直接惩罚"不输出"。

### 5.2 数据证据

- `4-1统计图2`:GT 3 张表;pmc 计分 15 张(mean 0.087);mix 计分 **0 张**(文件为空,不是 0 分)。
- `3-1跨页重复表头`:pmc 13 张(mean 0.604)→ mix 0 张。
- 重归一验算(mix,4-1统计图2):0.3×0.0277 + 0.3×0.0606 + 0.1×0 = 0.0265,而 per-doc overall = 0.0378 = 0.0265/**0.7**。
- 零计分表文档数:pmc 66 / mix 66(净发生率未涨,构成轮换)。

### 5.3 问题总结

mix 的 TEDS 0.3908 对"不输出表格"偏乐观,真实表格损伤被低估(部分损伤转移为 text/order 塌,如 4-1统计图2 text_acc 0.028)。**跨路比较 TEDS 必须同时报告计分表数与零计分表文档数。**

### 5.4 解决方案

1. 报告规范:任何跨路 TEDS 对比附带计分表数、零计分表文档数;
2. 把这两条写进 `evaluation_pitfalls`(只影响解读,历史分数不改);
3. 验收门增加计分表覆盖要求(§10)。

个例补充(现象四的边缘):`广东特检院_安全报告1_5` 长度比 0.97→0.77、中段缺失 ~700 字符、尾部同点截断,per-doc overall 0.707→**0.0**——评分对中段缺失的响应不成比例(对齐级联),且检测规则不触。建议检测规则增加 0.66-0.8 长度比带的人工抽检项(低优先)。

## 6. 复核方法

四个脚本(本地 `evaluation/review_20260918/`,同件曾于 jovyan /tmp 运行):`verify1.py`(官方复现/反事实/检测规则/计数/曲线/title87/页数拆分)、`verify2.py`(GT 规模/union 对比/长尾/**循环取证**/数据统计/spage 抽查)、`verify3.py`(计分表池/重归一/ATX 中位/GT 侧重复率/title 分解/32k 检查)、`verify4.py`(spage 对齐/TEDS 总量分解/关键篇 overall)。

复核过程中的四个口径澄清(避免后人重蹈):

1. **聚合粒度**:text/order 为 doc 加权(每篇 1 个 edit 均值),TEDS 为表加权;0827 三路只有全局聚合件,swp2_/swp3_ 才有逐篇件。
2. **官方 pmc 值 = 原始池剔除 `5-1双栏表格2`**(matching 不收敛篇):不剔则 text 0.7615/TEDS 0.4677(n262),剔后逐位复现 0.7658/0.4686(n258)。反事实定义=剔**严格 8 篇且不含该篇**(pmc 池另剔之),base 0.5002/fc 0.4999/pmc 0.5296 逐位复现。
3. **统计退化现象用中位数**:ATX 行/篇均值 42.2 是复读文档绑架的假信号,四路中位数全为 0。
4. **spage 2,000 篇与 pmc16k 9,284 篇零重叠**(独立拆分来源):无重复泄漏;目标 2,000/2,000 含 ATX、p50 4,158 字符、78% 页切截断(预期内),未发现构造事故;页图-文本对齐需人工抽 3-5 张(纯文本不可验)。
