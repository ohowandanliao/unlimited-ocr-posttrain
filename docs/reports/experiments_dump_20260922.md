## 3. 实验二:解码期复读抑制旁路(bypass v1)

### 3.1 设计

- 推理路径与主协议完全一致(同服务、同解码参数),仅在 logits processor 链尾追加抑制器:每 64 个生成 token 解码已生成文本,数字归一(数字串→#、td/tr/th 标签去属性、空白折叠)后,若文末存在 ≥3 次"链式相邻"(相邻出现结束位置差 ≤ L+gap=32)的 ≥256 字符重复块,强制 EOS。未触发文档生成结果与主协议逐位一致。
- 对象:两轮失效文档并集 19 篇(四规则对 pmc16k+mix1623 pred_clean 自算,pmc16k 11 篇+mix1623 12 篇、交集 4 篇)+ 健康对照 3 篇(4-2段落中带「图x-x」、1-2无线表1、1-3单元格内换行1)。
- 模型:ckpt-1623(mix1623 同款权重)。
- 调参史:初版判据有 bug(rfind 上界把末尾出现自身排除,邻接校验永假 → 0 触发);修复后单测四类循环全触发、两类合法例(仅 2 次的空表格行、分散重复)不触发;min_block 32→256 因 64/128 档误伤合法连号标题。

### 3.5 结论与残留问题

- **分数几乎不动**(TEDS ±0.0006、text edit −0.007、order +0.008)→ 解码期截断不提分:病篇主形态是"起步即偏"(第 0 token 即偏离 GT),循环就是全部输出,截断后内容依然缺失,失效从复读/过生成转为塌缩。
- 止损价值成立:不再产出 3 万 token 垃圾、matching 不收敛消失(5-1双栏表格2 本轮可出分)、推理时间大降。
- 与"+4.8pp 修复估算"不矛盾:该估算前提是恢复到第一轮水平(产出正确内容),路径在训练/配方侧。
- 残留:对照篇 4-2段落(38 页)误触发(1,067 token,合法重复结构被归一判为循环);珠海机场_工作证_6 触发过晚(仍 4.3×GT)。下一步:GT 感知长度上限 `max(16384, GT字符/1.8+4096)` 作第二道保险。
- 实施事件:2 篇截断致未闭合壳(4-1统计图1/4-2段落)按坑14 --aggressive。

## 8. 已知评分口径问题(解读任何数字前必读)

1. **未输出表格不计 0**:TEDS 评分池=可匹配的 pred 表格;模型未输出的 GT 表格从分母消失。例:4-1统计图2 mix1623 计分 0 张(文件空,非 0 分);pmc16k 计分 15 张(均值 0.087)。单篇缺 TEDS 分量时 Overall 按 /0.7 重归一。→ 跨路线比 TEDS 必须带计分表数(全库:194→149 等)。
2. **title 分量**:原 AgentBuilder title 在 grounding 协议下结构性塌零;所有引用的 title87 均为 87 篇重建口径重测。
3. **0827 与新路线推理 max_length 不同**(20,480 vs 32,768):影响失效检出率(预算小循环跑不长)。
4. **失效名单轮换**:跨路线比较失效"数"之外必须看名单(§7),如 2-1横向合并在 mix1623 修复、cont1623 又病(dup0.72)。
5. mix1450 为 mid-cosine 中间点;cont1623 有 lr 重铺+数据二遍(§4.1 口径警告)。
6. 聚合粒度:text/order 文档加权、TEDS 表加权——失效篇在文档口径被稀释(12 篇仅 −2.0pp)、在表加权口径放大(12 篇占表格池 29%,−3.8pp)。
