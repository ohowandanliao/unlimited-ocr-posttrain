## 评测 Prompt 矩阵

> Prompt 口径的完整标准、各轮评测审计和夏桢模型重测方案见 `docs/evaluation_prompt_matrix_2026-09-01.md`（唯一标准）。

评测时 prompt 由“页数 + 是否是主 Base + 是否有 MinerU 标题提示”决定：

| 场景 | 单页 | 多页 | MinerU 标题段 |
|---|---|---|---|
| 正式主 Base | `<image>document parsing.` | `<image>Multi page parsing.` | 永不添加 |
| 普通 READoc Full-CE / Title-weighted（无 Title Prior） | `<image>document parsing.` | `<image>Multi page merge.` | 永不添加 |
| 当前两套 Title Prior 模型，91 个有标题文件 | 对应页数的基础 prompt，再追加标题段 | 对应页数的基础 prompt，再追加标题段 | 添加 |
| 当前两套 Title Prior 模型，38 个无标题文件 | `<image>document parsing.` | `<image>Multi page merge.` | 不添加 |
| 夏桢历史 Base/Title-mask | 依历史入口 | `Multi page merge.` | 仅历史 diff，不用于正式主结论 |

本次正确 manifest 的四类实际数量（每个训练模型各一份）是：

- 单页 + 有标题：73；
- 单页 + 无标题：36；
- 多页 + 有标题：18；
- 多页 + 无标题：2。

标题段的固定外壳是：

~~~text
The following headings are extracted from the MinerU parsing result of the same document.
Use them only as structural hints.
Verify and correct the heading text, heading levels, ordering, and document structure according to the document images.
Do not blindly copy the MinerU headings if they conflict with the document images.

### MinerU headings
...

### Final corrected Markdown
~~~

标题是从 MinerU Markdown 确定性抽取的结构提示，不是人工修正后的答案；模型必须根据图片核验。
Base 请求不使用这段提示。
